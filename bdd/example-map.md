# Example Map — 步行/自駕導航跟隨真實速度

## 🟨 Story
As a 旅客, I want 導航跟著我真實的 GPS 位置前進, so that 我不會還沒走到就被帶到目的地。
（修正：舊版用固定時間模擬，按下導航幾秒就「抵達」，不符實際步行。）

## 🟦 Rules（藍卡）
1. 導航進度由真實 GPS 決定，不是固定時間。
2. GPS 會吸附到規劃路線（Snap-to-Road），抑制 5–15m 漂移。
3. 每個景點抵達只觸發一次（語音＋脈衝）。
4. GPS 1Hz，畫面以 60fps 平滑插值（不跳動）。
5. 無定位權限/桌機測試時，提供「模擬行走」示範模式（1.4 m/s），且明確標示為模擬。

## 🟩 Examples（綠卡）
- 有一次…使用者站著不動 → 進度 0、不會抵達。
- 有一次…使用者走到 120m → 進度 ≈120m、剩餘 ≈280m。
- 有一次…GPS 偏離 15m → 吸附回線上，進度正確。
- 有一次…進度由 240m→260m 越過 250m 的景點 S → 抵達 S 一次。

## 🟥 Questions（紅卡）
- OSRM 公開測試站 foot profile 可能不穩 → 失敗時以直線路線 fallback（已處理）。正式版改 MapKit/商用 API。
- 室內/地下無 GPS → 降級：維持上一次進度，不前進（可接受）。

## 關卡
- 關卡A（就緒）：✅（行為單一、一個迭代可完成）
- 關卡B（措辭核准）：使用者已明確指定行為，視為核准，最終以關卡D驗收為準。
