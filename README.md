# JanGo・櫻旅 3D 日本旅遊沉浸式導航

網頁版（PWA）日本旅遊 3D 沉浸式導航 App。技術：MapLibre GL JS（3D 底圖＋建物）、Three.js（程式化車／旅人）、OpenFreeMap、Open-Meteo（天氣）、OSRM（示範路線）、Web Speech（語音）。

- 入口：`index.html`（單檔，可直接部署到任何靜態主機 / Vercel / GitHub Pages）
- 首版地區：東京、大阪、京都、北海道
- 可包成 Android（TWA）與 iOS（Capacitor）送審

地圖資料 © OpenStreetMap contributors (ODbL)，向量圖磚 OpenFreeMap。
